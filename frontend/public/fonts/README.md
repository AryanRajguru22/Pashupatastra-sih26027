# Self-hosted fonts

The console loads no font or script from the internet, so the demo runs offline.
These latin-subset `woff2` files were downloaded once from Google Fonts
(fonts.gstatic.com) on 2026-09-26 and are referenced by `src/app/fonts.css`.

| File | Family | Licence |
|---|---|---|
| BodoniModa-normal-latin / -italic-latin | Bodoni Moda (variable, wght 400-900) | SIL OFL 1.1 |
| Manrope-latin | Manrope (variable, wght 200-800) | SIL OFL 1.1 |
| SpaceMono-{normal,italic}-{400,700}-latin | Space Mono | SIL OFL 1.1 |
| MaterialSymbolsOutlined-opsz24-wght400-fill0-1 | Material Symbols Outlined (opsz 24, wght 400, FILL 0..1) | Apache 2.0 |
